#AI생성

입력한 문구를 도트 매트릭스(LED 전광판)로 그려주는 편집기. 폰트를 오프스크린 캔버스에 그린 뒤 픽셀을 읽어 도트로 바꾸기 때문에 한글·영어·이모지·특수문자가 전부 그대로 나온다.
여기서 만든 설정은 **프리셋으로 저장**하거나 **코드로 복사해서 다른 노트에 붙여넣을** 수 있다.

```dataviewjs
await dv.view("미디어들/전광판", { editor: true })
```

## 사용법

### 문구와 연출
문구는 여러 개 넣을 수 있고 위에서부터 순서대로 돌아간다. 문구마다 등장 효과, 표시 시간(초), 속도를 따로 준다. 속도 칸을 비워두면 아래 `움직임`의 전체 속도를 따라간다.

| 효과                         | 설명                                |
| -------------------------- | --------------------------------- |
| 즉시 / 점멸                    | 바로 켜기, 깜빡이기                       |
| 좌로 흐름 / 우로 흐름              | 흘러가는 전광판. 표시 시간 대신 문구 길이로 시간이 정해짐 |
| 위·아래·좌·우로 밀기               | 앞 문구를 같이 밀어내며 교체                  |
| 페이드 / 와이프 / 커튼 / 디졸브 / 타이핑 | 밝기, 한쪽부터, 가운데부터, 도트 랜덤, 글자 순서대로   |

그 밖에 **슬롯머신**은 글자마다 위아래로 굴러가다(위아래가 이어짐) 왼쪽 글자부터 차례로 멈추고, 글자 수에 맞춰 전환 시간이 늘어난다(최대 3초). **플래시**는 화면 전체가 한 번 번쩍인 뒤 문구가 켜지는데, 광과민성 때문에 1초 안에 두 번은 번쩍이지 않는다.

화면보다 문구가 길면 고른 효과를 먼저 보여준 뒤 자동으로 흘러간다. 첫머리를 왼쪽에 붙여 효과로 등장시키고, 잠깐(0.8초) 멈춘 뒤 문구 끝이 오른쪽에 닿을 때까지 흘러가고, 거기서 표시 시간만큼 머문 다음 다음 문구로 넘어간다. 이때 표시 시간은 "끝까지 흐른 뒤 머무는 시간"이 된다. 흐르는 속도는 문구 속도(비우면 전체 속도)를 따른다.

`이어짐`(코드로는 `chain: true`)을 켜면 그 문구 **자기 자신이 반복**된다. 다른 문구와 이어 붙지는 않는다. 반복 사이는 한 줄로 이어 쓴 것과 같은 글자 간격이고, 더 띄우고 싶으면 `움직임`의 `이어짐 추가 간격`(코드로는 `gap`, 칼럼 수)을 올린다.

- **정적인 효과**(즉시, 점멸, 밀기, 페이드, 와이프, 커튼, 디졸브, 타이핑) — 화면에 들어가는 만큼 반복해서 가운데 정렬로 채우고 흐르지 않는다. `★` 하나면 `★★★★★`가 고른 효과로 나타나 멈춰 있다. 한 번도 다 안 들어갈 만큼 긴 문구는 반복 없이 위의 긴 문구 방식대로 움직인다
- **좌로 / 우로 흐름** — 표시 시간 동안 같은 문구가 이어서 들어오고, 남은 것이 다 빠져나가면 다음 문구로 넘어간다. 문구가 하나뿐이면 끝없이 흐른다

### 글자 마크업
문구 칸에서 글자를 드래그해 선택하고 색·효과 버튼을 누르면 마크업이 씌워진다. 형식은 `{속성 속성:글자}`이고, 속성은 공백으로 여러 개 나열할 수 있다.

| 속성                 | 뜻                                                                              | 보이는 모드  |
| ------------------ | ------------------------------------------------------------------------------ | ------- |
| `#ff2d2d` / `#f00` | 정해진 색                                                                          | 듀오톤·풀컬러 |
| `무지개`              | 글자 순서대로 색상환을 돈다 (고정)                                                           | 듀오톤·풀컬러 |
| `흐름`               | 그라데이션 무지개가 화면을 가로질러 흘러간다. `흐름(#ff0000,#0000ff)`처럼 색을 적으면 그 색들 사이 그라데이션이 흐른다                                                       | 듀오톤·풀컬러 |
| `반짝`               | 색을 돌려 가며 바꾼다. 태그 안 글자가 다 같이 바뀐다. `반짝(#ff0000,#ffffff)`처럼 색을 적고, 생략하면 지금 색 ↔ 흰색 | 듀오톤·풀컬러 |
| `깜빡`               | 그 부분만 점멸                                                                       | 전부      |

- **속성 섞기**: `{#ff0000 깜빡:SALE}` — 빨간 SALE만 깜빡인다
- **태그 안에 태그**: `{흐름:오늘의 {깜빡:특가}}` — 안쪽은 바깥 속성을 물려받는다. 색 계열(색·무지개·흐름·반짝)은 안쪽 것이 이기고, 깜빡은 바깥에서 켰으면 안쪽도 깜빡인다
- 속성으로 읽을 수 없는 `{`나 짝 없는 `}`는 그냥 글자로 나온다
- 이모지는 색 계열 속성을 무시하고 원래 색을 지킨다 (깜빡은 적용)
- **흐름·반짝에 색 넣기**: 문구 칸에서 `{반짝:…}`이나 `{흐름:…}` 태그 안에 커서를 두거나 블록을 잡고 색 버튼(또는 직접 고른 색)을 누르면, 글자를 감싸는 대신 그 태그의 색 목록에 추가된다. `{반짝:SALE}` → `{반짝(#ff0000):SALE}` → `{반짝(#ff0000,#ffffff):SALE}`. 태그가 겹쳐 있으면 가장 안쪽의 색 계열 속성을 보고, 그게 단색·무지개면 평소처럼 선택 글자를 감싼다
- `마크업 지우기`는 선택한 부분(선택 안 하면 문구 전체)의 태그를 벗긴다

색을 지정하지 않으면 **옵시디언 강조색**으로 나온다. 단색 모드는 LED가 한 색뿐이라 색 계열 속성은 안 보이고 깜빡만 동작한다. 흐름은 풀컬러에서 계조를 올릴수록 부드럽고, 듀오톤에서는 세 색 띠가 흐르는 모양이 된다.

### 색 표현
실제 전광판 하드웨어가 색을 내는 방식을 흉내낸 세 가지 모드.

- **단색** — LED 한 종류. 문구 색 하나로만 나온다
- **듀오톤** — 픽셀 하나에 LED가 두 개뿐인 2색 패널. 표현 가능한 색이 `A / B / 둘 다 켠 중간색` 셋뿐이라, 지정한 색을 두 LED 조합으로 근사한다. 기본값은 강조색과 그 **보색**이고, 서브픽셀을 켜면 픽셀 안의 LED 두 알이 따로 보인다 ([[디지털 색채#듀오톤]])
- **풀컬러** — RGB 서브픽셀. 계조를 낮추면 시중 간판 특유의 색 제한이 생긴다 (2단계 = 8색)

그 밖에 밝기, 도트 모양·크기, 잔광, 모듈 경계선(패널 이어붙인 자국), 가로 칼럼 수 고정 같은 하드웨어 쪽 설정이 있다.

### 도트 그림
문구 줄의 `그림` 버튼을 켜면 문구 칸이 여러 줄 칸으로 바뀌고, 글자 대신 도트를 직접 찍는다. 한 줄이 도트 한 행이다.

- `.`이나 공백은 꺼짐, `#`은 문구 색
- 다른 글자는 코드의 `palette`에서 색을 찾는다. 없으면 문구 색
- 행 수보다 짧으면 세로 가운데에 놓이고, 길면 가운데만 보인다
- 등장 효과·이어짐·반전이 글자와 똑같이 먹는다. 타이핑·슬롯머신은 칼럼 한 줄씩 진행된다
- `그림`을 다시 끄면 원래 적어뒀던 문구로 돌아간다

```js
{ messages: [{
    text: "", effect: "slot", chain: true,
    art: ["..rr.rr..", ".rrrrrrr.", "..rrrrr..", "...rrr...", "....r...."],
    palette: { "r": "#ff3355" }
}] }
```

### 이모지
이모지는 컬러 글리프라 그냥 도트로 바꾸면 색이 날아가 통짜 덩어리가 된다. 그래서 색 모드마다 따로 처리한다.

- **단색** — 이모지의 밝기를 [[모빌리티비전시스템#오츄 알고리즘|오츄 알고리즘]]으로 두 묶음으로 나눠 밝은 쪽만 켠다. 얼굴은 켜지고 눈·입은 꺼져서 모양이 읽힌다
- **듀오톤 / 풀컬러** — 글리프의 원래 색을 도트마다 그대로 쓴다. 듀오톤은 그 색을 두 LED 조합으로 근사한다

`©`, `™`처럼 이모지 범위에 있어도 흰 글자로 그려지는 기호는 일반 글자로 취급해서 문구 색을 따른다.

### 배경 반전
문구 줄마다 있는 `반전` 버튼을 켜면 그 문구가 나올 때 글자 자리만 꺼지고 나머지 도트가 전부 켜진다. 코드로는 문구에 `invert: true`를 넣는다. 문구가 바뀌는 전환 중에는 새로 나오는 문구 기준으로 화면 전체가 반전된다. 배경색은 그 위치에 있는 글자의 색을 따르므로, 글자별 색 마크업이 배경의 색 구역으로 그대로 나온다(듀오톤/풀컬러). 켜진 도트가 많으면 번진 빛이 꺼진 글자를 덮어버려서 반전 중에는 잔광이 꺼진다.

### 프리셋
이름을 적고 저장하면 [[전광판 프리셋]]에 한 줄로 쌓인다. 다른 기기에서도 볼트만 있으면 그대로 불러와진다.

### 다른 노트에 붙이기
편집기 맨 아래 `다른 노트에 붙이기`의 코드를 복사해 아무 노트에나 붙이면 그 노트에서 똑같이 돈다. 짧게 쓰고 싶으면 문자열 하나만 넘겨도 된다.

```dataviewjs
await dv.view("미디어들/전광판", "오늘도 수고하셨습니다")
```

```dataviewjs
await dv.view("미디어들/전광판", "프리셋:지하철 안내")
```

넘길 수 있는 것: `"문구"` · `["문구1", "문구2"]` · `"프리셋:이름"` · `{ messages: [...], rows: 9, ... }`

### 코드 불러오기
편집기 맨 아래 `코드 불러오기` 칸에 다른 노트에 붙였던 dataviewjs 블록(또는 JSON)을 붙여넣고 `편집기로 불러오기`를 누르면 그 설정이 편집기로 들어온다. 고친 뒤 다시 코드를 뽑거나 프리셋으로 저장하면 된다.

- 붙여넣은 코드는 실행하지 않고 읽기만 한다. 그래서 편집기에서 뽑은 JSON(키에 따옴표 있음), `"문구"`, `["문구1", "문구2"]`, `"프리셋:이름"`만 받는다
- 손으로 고치다 숫자 자리에 글자가 들어가는 식으로 타입이 틀린 설정은 기본값으로 되돌린다

## 구조
- 엔진: `미디어들/전광판/view.js`, 스타일: `미디어들/전광판/view.css`
- 프리셋 데이터: [[전광판 프리셋]]
- 이 노트는 그 엔진을 편집기 모드로 부르는 껍데기라, 연출을 고치려면 `view.js`를 보면 된다
