# 타일맵 게임 · 편집기 사용법

`/service/tilemap` 편집기로 맵을 만들고, 만든 맵은 이 폴더(`public/game`)에 파일로 저장된다.
게임(comictest1 페이지의 Monitor 안)은 이 폴더의 파일을 읽어서 돈다.

- 한 칸: **64×64px**
- 게임 화면: **710×540px**
- 편집기는 **로컬 개발 모드(`npm run dev`)에서만** 열린다. 배포된 사이트에서는 잠겨 있고, 게임은 커밋된 파일을 읽기만 한다.

---

## 1. 폴더 구조

```
public/game/
  project.json          타일 목록, 캐릭터 설정, 시작 맵, 맵 파일 목록
  maps/
    village.json        맵 하나 = 파일 하나 (파일 이름 = 맵의 "파일 이름")
    house.json
  tiles/                타일 그림 (png·gif·jpg·webp)
  backgrounds/          배경 그림
  characters/           캐릭터 스프라이트 시트
  README.md             이 문서
```

그림은 폴더에 **파일을 넣기만 하면** 편집기 목록에 뜬다(편집기에서 **그림 폴더 다시 읽기**).
맵·타일·캐릭터 설정은 편집기에서 **저장**을 누르면 위 JSON 파일들에 바로 기록된다.

---

## 2. 기본 흐름

1. `npm run dev` 실행 → 브라우저에서 `http://localhost:3000/service/tilemap`
2. 그림을 `tiles/`, `backgrounds/`, `characters/`에 넣고 **그림 폴더 다시 읽기**
3. 타일을 고르고 맵에 칠하기, 충돌·이벤트·시작 위치 정하기
4. **▶ 테스트 플레이**로 바로 걸어 보기
5. **저장** → `project.json`, `maps/*.json`에 기록 (바뀐 파일만 다시 씀)
6. `public/game` 폴더를 커밋·배포하면 사이트 게임에도 반영

저장 안 한 변경이 있으면 상태줄에 **● 저장 안 됨**이 뜨고, 저장 버튼이 주황색이 된다. 그 상태로 창을 닫으려 하면 한 번 묻는다.

## 3. 화면 위쪽 버튼

| 버튼 | 하는 일 |
| --- | --- |
| ▶ 테스트 플레이 / ■ 테스트 끝내기 | 지금 편집 중인 내용으로 게임을 바로 돌려 본다 (저장 안 해도 됨) |
| 저장 | `project.json` + `maps/*.json`에 기록. 목록에서 빠진(삭제·이름 바꾼) 맵 파일은 지운다 |

| 그림 폴더 다시 읽기 | `tiles`·`backgrounds`·`characters` 폴더를 다시 읽어 목록을 갱신한다 |

## 4. 맵 칠하기

### 도구

| 도구 | 사용법 |
| --- | --- |
| 그리기 | 고른 타일로 칸을 칠한다. 클릭·드래그 가능 |
| 지우개 | 지금 레이어의 칸을 비운다 |
| 충돌 | 칸마다 통과 여부를 직접 정한다 (아래 "충돌" 참고) |
| 이벤트 | 빈 칸을 누르면 이벤트가 생기고, 이벤트 칸을 누르면 오른쪽에서 고칠 수 있다 |
| 시작 위치 | 이 맵에서 처음 서는 칸 (주황 "시작" 표시) |

### 레이어

| 레이어 | 용도 |
| --- | --- |
| 바닥 | 풀, 길, 물처럼 깔리는 칸 |
| 오브젝트 | 나무, 벽, 바위처럼 바닥 위에 올리는 것 |
| 캐릭터 위 | 캐릭터보다 **위에** 그려지는 것 (나뭇잎, 지붕 끝 등). 충돌에는 영향 없음 |

그리는 순서: 배경 → 바닥 → 오브젝트 → 이벤트 그림 → 캐릭터 → 캐릭터 위

### 보기 설정

- **확대**: 편집 화면에서 한 칸을 16~64px로 보여준다 (게임에는 영향 없음)
- **격자**, **충돌 표시** 켜고 끄기

### 편집 화면 표시 색

| 표시 | 뜻 |
| --- | --- |
| 빨간 칸 | 막힌 칸 |
| 초록 테두리 | 충돌 도구로 "지나가기"를 강제로 지정한 칸 |
| 노란 테두리 | 말 걸기 이벤트 |
| 파란 테두리 | 다른 맵으로 이동 이벤트 |
| 주황 "시작" | 시작 위치 |

## 5. 충돌 (지나갈 수 있는지)

칸 하나가 막혔는지는 아래 순서로 정해진다. 위에 있는 게 이긴다.

1. 충돌 도구로 **막기** 지정 → 막힘
2. 충돌 도구로 **지나가기** 지정 → 통과 (막힌 타일 위라도)
3. 그 칸 이벤트의 **막힘** 체크
4. 바닥·오브젝트 타일의 **막힘** 체크 (캐릭터 위 레이어는 보지 않음)
5. 맵 밖은 항상 막힘

충돌 도구에서 **막기**/**지나가기**를 고르고 칸을 누른다. 이미 같은 값인 칸을 다시 누르면 **자동**(타일 설정 따름)으로 돌아간다.

## 6. 타일

오른쪽 **타일** 칸에서 관리한다. 팔레트에서 타일을 누르면 그 타일이 선택되고 도구가 **그리기**로 바뀐다.

| 항목 | 설명 |
| --- | --- |
| 이름 | 편집기에서 보이는 이름 |
| 그림 | `tiles/` 폴더의 파일 중에서 고른다. **없음**이면 코드로 그린 목업 그림 |
| 목업 | 그림이 없을 때만 보임. 색과 무늬 |
| 막힘 | 체크하면 캐릭터가 지나갈 수 없다 |

- **+ 타일 추가** / **선택 타일 삭제** (삭제하면 모든 맵에서 그 타일이 지워진다. 마지막 하나는 못 지움)
- 그림은 **64×64**로 그리면 딱 맞다. 크기가 달라도 한 칸(64×64)에 맞춰 늘리거나 줄여서 그린다.
- gif는 브라우저가 움직여 주는 만큼 움직인다.

## 7. 캐릭터 스프라이트

`characters/`에 스프라이트 시트를 넣고 **캐릭터 → 그림**에서 고른다. **기본 캐릭터 (목업)**을 고르면 코드로 그린 캐릭터로 돌아간다.

기본값은 **쯔꾸르 방식**이다.

```
        0칸      1칸      2칸
0줄  [아래 걷기1][아래 서기][아래 걷기2]
1줄  [왼쪽 ...  ]
2줄  [오른쪽 ...]
3줄  [위 ...    ]
```

| 항목 | 설명 |
| --- | --- |
| 한 칸 | 프레임 하나의 가로×세로(px). 64보다 크면 발을 칸 바닥에 맞추고 위로 삐져나오게 그린다 (예: 64×96) |
| 걷기 칸 | 가로 프레임 수. **3칸이면 가운데(1칸)가 서 있는 모습**이고 0-1-2-1 순서로 걷는다. 그 밖의 수는 0칸이 서 있는 모습이고 0부터 차례로 돈다 |
| 방향 줄 | 아래·왼쪽·오른쪽·위가 각각 몇 번째 줄인지 (0부터) |
| 발 위치 | 발이 떠 보이거나 파묻혀 보일 때 보정(px). +면 아래로 |

설정 아래의 미리보기에서 네 방향이 나란히 걷는 모습으로 바로 확인할 수 있다.

## 8. 맵

| 항목 | 설명 |
| --- | --- |
| 선택 | 편집할 맵 |
| 이름 | 편집기에서 보이는 이름 (한글 가능) |
| 파일 이름 | `maps/(파일 이름).json`. **영문·숫자·`-`·`_`만** (64자까지). 적고 Enter 또는 **바꾸기**. 바꾸면 시작 맵과 다른 맵의 이동 이벤트 목적지도 같이 바뀌고, 저장할 때 예전 파일은 지워진다 |
| 크기 | 가로×세로 칸 수 (4~80). 줄이면 바깥쪽 칸과 그 안의 이벤트는 사라진다 |
| 배경 | `backgrounds/` 폴더의 그림. **맵 전체에 맞춤**이면 맵 크기(가로 칸×64, 세로 칸×64)에 맞춰 늘리고, **반복**이면 원래 크기로 깔아 반복한다 |
| 바탕색 | 배경 그림이 없는 곳의 색 |

- **+ 맵 추가**: 16×12 새 맵 (파일 이름 `map3` 같은 식으로 자동으로 붙음)
- **시작 맵으로**: 게임을 켜면 이 맵의 시작 위치에서 시작
- **맵 삭제**: 마지막 하나는 못 지움. 저장하면 그 맵 파일도 지워진다

배경 그림을 맵과 딱 맞게 그리려면 **가로 = 칸 수×64, 세로 = 칸 수×64** 크기로 그리면 된다. (예: 16×12 칸 맵 → 1024×768px)

## 9. 이벤트

**이벤트** 도구로 빈 칸을 누르면 만들어진다 (기본: 말 걸기 · 스페이스로 · 막힘).

| 항목 | 설명 |
| --- | --- |
| 종류 | **말 걸기**(대사 창) / **다른 맵으로 이동** |
| 발동 | **스페이스로**: 그 칸을 바라보고 조사하면 / **밟으면**: 그 칸에 올라서는 순간 |
| 대사 | 말 걸기의 내용. 줄바꿈 가능. 한 창에 **4줄까지** 보이고 넘치면 …로 잘린다 |
| 목적지 | 이동할 맵과 도착 칸(x, y) |
| 그림 | 이벤트 칸에 같이 그릴 타일 (상자, 문 등) |
| 막힘 | 체크하면 그 칸을 밟을 수 없다 (말 거는 상자 등). 밟아서 발동하는 이벤트(문 등)는 꺼야 한다 |

좌표는 **맨 왼쪽 위 칸이 (0, 0)**이고 x는 오른쪽, y는 아래로 커진다.

**문 만들기 예시**: 마을 문 칸에 "다른 맵으로 이동 · 밟으면 · 막힘 끔" 이벤트 → 목적지는 집 안의 문 바로 안쪽 칸.
집 안의 문 칸에도 반대로 돌아오는 이벤트를 하나 둔다.
도착 칸은 문 칸이 아니라 **문 한 칸 앞**으로 잡는 게 좋다. 이동으로 도착한 칸에서는 바로 발동하지 않지만, 문 칸 위에 도착하면 한 발만 움직였다 돌아와도 다시 이동해 버린다.

## 10. 게임 조작

| 키 | 동작 |
| --- | --- |
| **화면 클릭** | 먼저 게임 화면을 한 번 눌러야 키가 먹는다 (안 누르면 안내 문구가 뜸) |
| W A S D / 방향키 | 한 칸씩 이동. 누르고 있으면 계속 걷는다 |
| 스페이스 / Enter / Z | 바라보는 칸 조사, 대사 창 닫기 |

- 한글 자판 상태에서도 WASD가 그대로 먹는다.
- 대사 창은 `.messagebox` 스타일(흰 바탕, 검정 테두리, 흰 외곽선)과 도트 폰트(`gal` = `public/fonts/GalmuriMono9.woff2`)를 쓴다.
- 맵이 화면보다 크면 카메라가 캐릭터를 따라가고, 작으면 가운데에 놓인다.

## 11. 파일을 직접 고칠 때

JSON을 손으로 고쳐도 된다. 파일을 연 채로 맵 모양이 보이도록 **한 줄에 한 행**씩 적혀 있다.

### project.json

```json
{
  "name": "샘플 마을",
  "tiles": [{ "id": "grass", "name": "풀", "color": "#4c9a3f", "pattern": "grass", "src": "/game/tiles/grass.png", "solid": false }],
  "player": { "src": "/game/characters/hero.png", "frameW": 64, "frameH": 64, "frames": 3,
              "rows": { "down": 0, "left": 1, "right": 2, "up": 3 }, "offsetY": 0 },
  "startMapId": "village",
  "maps": ["village", "house"]
}
```

- `player`가 없으면 기본 캐릭터
- `maps`의 순서가 편집기 맵 목록 순서

### maps/(파일 이름).json

| 키 | 내용 |
| --- | --- |
| `id` | 파일 이름과 같아야 한다 |
| `name`, `w`, `h` | 이름, 가로·세로 칸 수 |
| `layers.ground` / `object` / `overlay` | 행 배열. 칸마다 타일 id, 빈 칸은 `null` |
| `collision` | 행 배열. `-1` 자동, `0` 통과, `1` 막힘 |
| `background` | `{ "src": "/game/backgrounds/...", "color": "#12121a", "mode": "cover" \| "tile" }` |
| `spawn` | 시작 칸 `{ "x": 4, "y": 8 }` |
| `events` | 이벤트 목록 (`kind`: `message`/`warp`, `trigger`: `action`/`touch`, `text`, `to`, `tileId`, `solid`) |

행 개수나 칸 수가 모자라거나 넘치면 불러올 때 알아서 맞춘다.
**JSON 문법이 깨지면** 편집기가 오류를 보여주고 저장을 막는다 (샘플로 덮어쓰지 않도록). 파일을 고친 뒤 새로고침하면 된다.

## 12. 문제가 생기면

| 증상 | 확인할 것 |
| --- | --- |
| 넣은 그림이 목록에 없다 | **그림 폴더 다시 읽기**. 폴더(`tiles`/`backgrounds`/`characters`)와 확장자(png·gif·jpg·jpeg·webp) 확인 |
| 저장했는데 게임이 그대로다 | 게임 페이지 새로고침 |
| 캐릭터가 안 움직인다 | 게임 화면을 먼저 한 번 클릭 |
| 편집기에 "로컬 개발 환경에서만 열립니다" | 배포본에서 연 것. `npm run dev`로 띄운 주소로 열기 |
| 편집기가 "불러오는 중"에서 멈춤 | 개발 서버가 떠 있는지 확인하고 Ctrl+Shift+R. 휴대폰 등 다른 기기에서 열 때는 `next.config.ts`의 `allowedDevOrigins`에 그 주소가 있는지 보고 개발 서버 재시작 |
| "맵 파일을 읽지 못했습니다" | 손으로 고친 JSON의 문법 오류. 오류에 나온 파일을 고치고 새로고침 |
| 캐릭터 발이 떠 보인다 | 캐릭터 → **발 위치** 조정 |

- 캐릭터 외의 스프라이트 애니메이션 (타일은 gif로 대신)
